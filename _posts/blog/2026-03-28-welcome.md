## How to Add Blog Entries

Create new markdown files in the `_posts/blog/` directory with the following naming format:

```
YYYY-MM-DD-title-of-post.md
```

### Front Matter

Each blog entry needs front matter at the top:

```yaml
---
category: blog
title: Your Entry Title
published: true
date: YYYY-MM-DD
---
```

### What You Can Include

- **Text and paragraphs** - Regular markdown
- **Headings** - Use `##` and `###` for structure
- **Images** - Add images with markdown syntax
- **Lists** - Both ordered and unordered lists work
- **Code blocks** - Use triple backticks
- **Links** - Regular markdown links
- **Iframes** - Embed videos or other content

The blog entries will automatically appear in reverse chronological order on the `/blog/` page.

## Example Entry Structure

```markdown
---
category: blog
title: My Latest Project
published: true
date: 2026-03-28
---

This is the main content of your blog post...

### Subheading

More details here with **bold** and *italic* text.

![Image description](image-url.jpg)
```

That's it! Your blog is ready to use.
